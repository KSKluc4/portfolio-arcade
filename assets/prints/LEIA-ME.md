# Prints dos projetos

Coloque aqui as imagens (PNG, JPG ou WebP) e aponte no `config.js`:

```js
'pilates-studio': {
  image: 'assets/prints/pilates-studio.png',
},
```

O print vira o fundo da tela de boot e aparece na tela de detalhes do projeto.
Uma imagem na proporção 16:9, com uns 1280px de largura, funciona bem.
